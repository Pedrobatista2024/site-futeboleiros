Política de Privacidade

Esta política explica como o Futeboleiros trata dados pessoais quando você usa o aplicativo e a lista online.

Última atualização: 20 de outubro de 2026.

1. Quem é responsável

O Futeboleiros é operado por Pedro Batista Neto. Para dúvidas, solicitações ou assuntos relacionados à privacidade, escreva para Futiboleiros2k20@gmail.com.

2. Dados tratados

Conforme os recursos utilizados, o aplicativo pode tratar dados de conta, como e-mail e identificador de autenticação; dados da organização; nomes, posições, contato, data de nascimento e fotos de jogadores inseridos pelo administrador; dados de partidas, placares e estatísticas; e informações necessárias para inscrições em listas online.

3. Finalidades

Usamos esses dados para autenticar usuários, criar e administrar organizações, organizar rachas, montar listas, registrar partidas e estatísticas, sincronizar dados entre aparelhos autorizados, gerar publicações e viabilizar backups escolhidos pelo usuário.

4. Lista online

Quando uma organização publica uma lista online, informações necessárias para a inscrição e identificação do jogador podem ser exibidas nessa página. A organização que criou a lista é responsável por decidir quais dados inserir e por obter as autorizações necessárias dos participantes.

5. Armazenamento e compartilhamento

Parte dos dados é mantida localmente no aparelho para permitir o uso do app com mais fluidez. Dados de organizações podem ser sincronizados com infraestrutura em nuvem para que aparelhos autorizados acessem a mesma organização. O Futeboleiros utiliza serviços de autenticação e banco de dados da Supabase e, quando escolhido pelo usuário, autenticação do Google. Não vendemos dados pessoais.

6. Segurança

O acesso às organizações depende de autenticação e permissões de membro. Apesar das medidas técnicas adotadas, nenhum serviço digital elimina todos os riscos. Proteja sua conta, sua senha e os backups exportados pelo aplicativo.

7. Retenção e exclusão

Os dados permanecem enquanto forem necessários para o uso da conta e das organizações. O responsável pela organização pode excluir uma organização e seus dados vinculados pelo aplicativo. Cópias locais e arquivos de backup exportados ficam sob responsabilidade de quem os possui e devem ser apagados quando não forem mais necessários.

8. Seus direitos

Você pode solicitar confirmação de tratamento, acesso, correção, eliminação e informações sobre o uso dos seus dados, observadas as hipóteses legais aplicáveis. Para isso, entre em contato pelo e-mail informado nesta política.

9. Alterações desta política

Esta política pode ser atualizada para refletir mudanças no aplicativo ou em obrigações legais. A versão vigente ficará disponível nesta página.
